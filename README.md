# Таро — расклады и колода из 78 карт

## 🎴 Новая функция: Галерея карт

### Что добавлено в версии 2.1

✨ **Полная галерея из 78 карт Таро**
- Просмотр всей колоды в удобной сетке
- Фильтры по мастям (Старшие арканы, Жезлы, Кубки, Мечи, Пентакли)
- Детальный просмотр каждой карты в модальном окне
- Описания прямого и перевернутого положений

### Как использовать

1. Нажмите кнопку **"🎴 Колода"** в верхнем меню
2. Просмотрите все карты или отфильтруйте по мастям
3. Кликните на любую карту для детального просмотра
4. В модальном окне изучите значения карты в обоих положениях

### Возможности галереи

- **Фильтрация**: Все карты, Старшие арканы, или конкретная масть
- **Детальный просмотр**: Модальное окно с полным описанием
- **Адаптивная сетка**: 
  - Desktop: 5-6 карт в ряд
  - Tablet: 3-4 карты в ряд
  - Mobile: 2-3 карты в ряд
  - Mobile Small: 1-2 карты в ряд

### Структура информации о карте

В модальном окне для каждого положения показано всё, что есть в данных:

- 🖼️ Символика — что изображено на карте
- 📖 Общее значение
- ❤️ Любовь и отношения
- 👥 Отношения с окружающими
- 💼 Работа и карьера
- 💰 Финансы
- 🏥 Здоровье
- 🧠 Психологический аспект
- 🕊️ Духовный аспект
- ⏳ Сроки
- 🔗 Сочетания с другими картами
- 💡 Совет
- 🔮 Ответ да/нет

Заполнены поля неравномерно, и то, чего у карты нет, не выводится:
символика, психологический и духовный аспекты, сроки и сочетания есть
только у 22 старших арканов; общее значение, любовь, отношения, работа,
финансы, здоровье, совет и ответ да/нет — у всех 78.

Ответ да/нет у старших арканов один на карту и выводится отдельным
блоком; у младших он разный для прямого и перевёрнутого положения
и показывается внутри каждого.

Расклад остаётся компактным: там выводятся общее значение, совет,
любовь, работа, финансы и здоровье.

## 🎨 Дизайн

Интерфейс собран по правилам iOS, телефон первичен.

### Тема
- Системная палитра iOS на переменных: светлая и тёмная,
  переключается по `prefers-color-scheme`
- Шрифт SF Pro через `-apple-system`, размеры по шкале iOS
  (17 px в тексте, 34 px в крупном заголовке)
- Закреплённая навигация с размытием, как в системных приложениях
- Сгруппированные списки со скруглением и волосяными разделителями
- Безопасные зоны (вырез, домашняя полоска) через `env(safe-area-inset-*)`
- Зоны касания не меньше 44 px, `prefers-reduced-motion` учитывается

### Компоненты
- **Расклады** — лента с горизонтальной прокруткой, у каждого чипа подпись
  (раньше это была сетка одинаковых кружков с одними эмодзи)
- **Фильтры колоды** — один ряд с прокруткой вместо трёх строк переносов
- **Карточка карты** — лист, выезжающий снизу, с ручкой и миниатюрой
  в шапке; текст виден сразу, а не за пределами экрана
- **Расклады на телефоне** складываются в столбец: Кельтский крест
  в четыре колонки на узком экране нечитаем

### Адаптивность
Одна точка перелома — 700 px. Ниже неё раскладки одноколоночные,
выше появляются сетка позиций расклада и две колонки в толкованиях.
Сетка карт подстраивается сама через `auto-fill`.

## 🔧 Кастомизация

### Изменить цветовую схему
Отредактируйте CSS-переменные в `:root`:

```css
:root {
    --accent-primary: #007aff;  /* Ваш цвет */
    --accent-secondary: #5ac8fa;
}
```

### Изменить количество карт в ряду
Отредактируйте `.deck-grid`:

```css
.deck-grid {
    grid-template-columns: repeat(auto-fill, minmax(180px, 1fr));
    /* Измените 180px на нужное значение */
}
```

## Авторская книга «Карта как зеркало»

Практическое продолжение доступно из книги, обучения и атласа. В `data/author-materials.json` собраны 78 описаний карт, 34 урока по главам, 36 материалов Ленорман с примерами пар и 8 пошаговых практик. Это дополнение; исходный текст рукописи не заменён.

Каждая карта Таро содержит образ, смысл, ресурс, трудность, перевёрнутый ракурс, вопрос и собственное упражнение. Из описания можно открыть практику с выбранной картой. Задание сохраняется вместе с первым введённым ответом в необязательном поле `bookExercise` записи дневника v2, проверяется при импорте и экранируется при показе. Старые записи совместимы. Уроки и Ленорман содержат самостоятельные задания и не создают фиктивных раскладов.

Прямые ссылки: `#study=cards&id=minor_arcana.wands.ten`, `#study=lessons&id=13`, `#study=lenormand&id=4`, `#study=practices&id=mirror`. Раздел загружается по запросу; поиск учитывает русские е/ё, для Таро есть фильтр по мастям. Проверка полноты и поведения: `node tools/test-author.js`.

Книга доступна из верхней навигации и обучения. `data/book.json` содержит полный отредактированный текст: 34 главы, пролог, эпилог и 18 источников. Описания 22 старших арканов связаны с атласом в обе стороны; младшие арканы ведут в главу 13. Поиск работает по названиям и полному тексту.

Ссылки вида `#book=12&b=5` открывают главу и абзац. Размер текста и последнее место чтения сохраняются только в текущем браузере (`polkas-book-v1`). Книга загружается отдельно от колоды; ошибка загрузки колоды не блокирует чтение.

Практика «Зеркало» сохраняется как совместимая запись дневника v2 с `bookPractice: true` и `bookChapter`. Она включает выбранную карту, вопрос, наблюдение, ассоциацию и следующий шаг; входит в существующий экспорт/импорт дневника. Это локальные записи, синхронизации между устройствами нет. Ответы автоматически сохраняются при вводе. Кнопка «Сохранить в дневник» позволяет повторить сохранение, если хранилище временно было недоступно.

Проверки: `node tools/test-book.js`. Дополнительный браузерный сценарий: запустить статический сервер на порту 8765, установить optional-зависимость Playwright и браузер, затем `node tools/test-book-browser.js`. Снимки сохраняются в игнорируемую папку `screenshots/`.
