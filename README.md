# ✨ Tarot Professional System - iOS Light Design + Deck Gallery

## 🎴 Новая функция: Галерея карт

### Что добавлено в версии 2.1

✨ **Полная галерея из 78 карт Таро**
- Просмотр всей колоды в удобной сетке
- Фильтры по мастям (Старшие арканы, Жезлы, Кубки, Мечи, Пентакли)
- Детальный просмотр каждой карты в модальном окне
- Описания прямого и перевернутого положений

### Как использовать

1. Нажмите кнопку **"🎴 Колода"** в верхнем меню
2. Просмотрите все карты или отфильтруйте по мастям
3. Кликните на любую карту для детального просмотра
4. В модальном окне изучите значения карты в обоих положениях

### Возможности галереи

- **Фильтрация**: Все карты, Старшие арканы, или конкретная масть
- **Детальный просмотр**: Модальное окно с полным описанием
- **Адаптивная сетка**: 
  - Desktop: 5-6 карт в ряд
  - Tablet: 3-4 карты в ряд
  - Mobile: 2-3 карты в ряд
  - Mobile Small: 1-2 карты в ряд

### Структура информации о карте

Для каждой карты в модальном окне показано:

**Прямое положение:**
- 📖 Общее значение
- ❤️ Любовь и отношения
- 💼 Работа и карьера
- 💰 Финансы
- 💡 Совет

**Перевернутое положение:**
- 📖 Общее значение
- ❤️ Любовь и отношения
- 💼 Работа и карьера
- 💰 Финансы
- 💡 Совет

## 🔧 Кастомизация

### Изменить цветовую схему
Отредактируйте CSS-переменные в `:root`:

```css
:root {
    --accent-primary: #007aff;  /* Ваш цвет */
    --accent-secondary: #5ac8fa;
}
```

### Изменить количество карт в ряду
Отредактируйте `.deck-grid`:

```css
.deck-grid {
    grid-template-columns: repeat(auto-fill, minmax(180px, 1fr));
    /* Измените 180px на нужное значение */
}
```
