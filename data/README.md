# Данные карт

Файлы в этом каталоге собираются из `js/data/*.js` командой:

```
node tools/js2json.js
```

Руками их не правят: правки вносятся в `js/data/`, после чего конвертер
запускается заново. Проверить данные, ничего не записывая:

```
node tools/js2json.js --check
```

## Что здесь лежит

| Файл | Что внутри |
| --- | --- |
| `cards.json` | Канонический файл: метаданные колоды и массив из 78 карт |
| `index.json` | Лёгкий индекс для галереи — имя, масть, путь к картинке |

Остальные выгрузки конвертер тоже создаёт, но в репозитории они не хранятся
(см. `.gitignore`): `cards.min.json` без отступов, `cards.jsonl` по карте на
строку, файлы по мастям и `cards.csv` при запуске с флагом `--csv`.

## Схема карты

```json
{
  "id": 0,
  "code": "major_arcana.00",
  "source": "js/data/major.js",
  "detail": "full",
  "name": "Шут",
  "name_en": null,
  "arcana": "major",
  "suit": null,
  "suit_ru": null,
  "number": 0,
  "rank": null,
  "img": "img/cards/maj00.jpg",
  "correspondences": {
    "element": "Воздух", "planet": null, "sign": null, "label": "Воздух"
  },
  "meanings": {
    "direct":   { "...": "..." },
    "reversed": { "...": "..." }
  }
}
```

| Поле | Значение |
| --- | --- |
| `id` | 0–77. 0–21 старшие арканы, дальше жезлы, кубки, мечи, пентакли |
| `code` | Канонический идентификатор по спецификации [Arcana Land](https://github.com/arcanaland/specifications): `major_arcana.00`, `minor_arcana.wands.ace` |
| `source` | Из какого файла взята карта |
| `detail` | `full` — подробное толкование, `short` — краткое, ещё предстоит дописать |
| `arcana` | `major` или `minor` |
| `suit` | `null`, `wands`, `cups`, `swords`, `pentacles` |
| `number` | Номер аркана или ранг карты в масти (1–14) |
| `rank` | `ace`, `two` … `ten`, `page`, `knight`, `queen`, `king`; `null` у старших |
| `correspondences` | Астрологические соответствия, см. ниже |

### Соответствия

Система — Золотая Заря; ей следует Уэйт, чья колода здесь нарисована. Таблица
лежит в `js/data/correspondences.js`, конвертер перепроверяет её деканы по
правилу и падает на расхождении.

| Поле | Значение |
| --- | --- |
| `element` | `Огонь`, `Вода`, `Воздух`, `Земля`; `null` у старших арканов с одной лишь планетой |
| `planet` | Планета старшего аркана или планета декана; `null` у тузов и двора |
| `sign` | Знак зодиака; `null` там, где привязки к знаку нет |
| `label` | Готовая подпись: `Марс`, `Сатурн в Весах`, `Огонь Земли`, `Корень стихии Воды` |

### Поля толкования

Одинаковые у `direct` и `reversed`. Схема единая для старших и младших
арканов: чего у карты нет — `null`, а не отсутствующий ключ.

## Что ещё не готово

Звезда, Луна, Солнце, Суд и Мир взяты из резервного `js/data/tarot_raw.js`
в кратком виде и помечены `detail: "short"`. Пока их подробные толкования не
написаны в `js/data/major.js`, приложение показывает 73 карты из 78.
