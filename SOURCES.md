# Происхождение материалов

Лицензия MIT в файле `LICENSE` покрывает **исходный код**: HTML, CSS,
JavaScript и скрипты в `tools/`. Картинки и тексты толкований — отдельный
разговор, и он здесь.

## Изображения карт — происхождение не установлено

В `img/cards` лежат 78 файлов 350x600 плюс рубашка. Откуда они взялись,
по самим файлам определить нельзя:

- EXIF пустой — ни автора, ни камеры, ни программы, ни даты;
- при 350x600 микротекст копирайта, если он на скане был, нечитаем;
- в истории репозитория все 79 файлов появляются одним коммитом `cc25f7e`
  с сообщением «Add files via upload» — источник там не назван.

Рисунки колоды Райдера — Уэйта — Смит изданы в 1909 году и находятся в
общественном достоянии: Памела Колман Смит умерла в 1951-м, и срок охраны
истёк везде, где он считается как жизнь автора плюс семьдесят лет. Но
общественное достояние у **рисунка** не делает свободным **конкретный файл**:
современное издание может быть перерисовано, а скан — сопровождаться
собственными условиями.

Поэтому: пока эти файлы не заменены, считать их свободными нельзя.

## Как это чинится

```
node tools/fetch-images.js --dry-run    только проверить
node tools/fetch-images.js              заменить и переписать этот файл
```

Скрипт берёт сканы с Викисклада, для каждого файла читает лицензию из
ответа API и отказывается качать что-либо, если хоть один файл не оказался
общественным достоянием. После успешной замены он перезаписывает этот файл
таблицей на 78 строк: карта, файл в репозитории, страница на Викискладе,
лицензия и автор — всё из ответов API, а не проставлено вручную.

Нужен доступ к `commons.wikimedia.org`. В окружении, где сеть закрыта
политикой прокси, скрипт остановится на HTTP 403 и ничего не заменит.

Если запускать негде — вкладка Actions, рабочий процесс «Картинки»: он
делает то же самое на раннере GitHub и открывает PR с результатом.

## Тексты толкований

Толкования лежат в `js/data/*.js` и попадают в `data/cards.json`. Их
происхождение так же не задокументировано: часть могла быть написана,
часть — заимствована из справочников. Пять старших арканов (Звезда, Луна,
Солнце, Суд, Мир) дописаны в этом репозитории.

Пока источник остальных не выяснен, MIT на них не распространяется.

## Астрологические соответствия

`js/data/correspondences.js` — таблица привязок по системе Золотой Зари.
Сами привязки — факты традиции, не объект авторского права; таблица собрана
здесь и покрывается MIT наравне с кодом.
